Privacy Policy – GVL Support

Support ("the bot") is the support assistant of the German Virtual League (GVL). It answers support questions from members using a knowledge base written by the GVL staff.

Data we collect

  • Message content: read only in one dedicated support channel, in order to answer the question asked there. Messages in all other channels are ignored.
  • Questions sent with /ask: the text of the question, in order to answer it.
  • Discord user and channel IDs: used to keep a short conversation context per user, so follow-up questions can be answered.
  • Roles: used to check whether a member may use staff commands or upload chants.
  • Chant uploads (staff only): the uploaded audio file, the chant name from the message and the uploader's username.

How we use this data

Data is used only to operate the bot's features: answering support questions, improving the knowledge base, and uploading chants for the league.

We do not sell this data or use it for any purpose outside the bot's operation.

Third-party services

  • Groq: the question text and matching knowledge base entries are sent to the Groq API to generate the answer.
  • Roblox: uploaded chant audio files are published as assets in the GVL Roblox group.

Data is not shared with any other third parties.

Storage and data retention

  • The conversation context (the last few messages per user) is kept in memory only and is deleted when the bot restarts.
  • Questions the bot cannot answer are posted in a staff-only review channel, so staff can add the answer to the knowledge base.
  • The knowledge base contains only entries written by staff, not member messages.
  • Other messages are not stored or logged.

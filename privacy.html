# Privacy Policy GVLBot ("the bot") is the official Discord bot of the German Virtual League (GVL). ## Data we collect - Discord User IDs and Server (Guild) IDs, to identify users and servers for bot functionality - Message content in specific channels, used only to detect spam and inappropriate language (bad word/spam filter) and to mirror messages between linked channels (Free Agent, Offers, Friendly, Global Chat) - Basic member information (join events, roles) for welcome messages and role/permission checks - Command usage data (which commands are used, when) ## How we use this data Data is used only to operate the bot's features: moderation (spam/word filtering, timeouts, global bans), channel linking, team/league information lookup, and standings image generation. We do not sell or share this data with third parties. Message content is not stored permanently beyond what is needed for the above functions and is not used for any purpose outside the bot's operation. ## Data retention Logs related to moderation actions (e.g. spam detections, bans) may be kept for server administration purposes.
